# Landau score convergence: reproducible experiments

Numerical code and archived results accompanying **Convergence of Alternating
Score--System Iterations for Regularized Landau Particle Dynamics**, by Yeoneung
Kim, Donghyun Lee, and Sung-Jun Son.

The experiments illustrate the regularized alternating score--system iteration,
its behavior under persistent score errors, and the static empirical
zero-regularization dichotomy. All numerical data are generated by the included
code from the prescribed configurations and random seeds. No external datasets
are used.

## Setup

Use Python 3.10 or later. From this directory, create a virtual environment and
install the dependencies:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

On Windows PowerShell, use `python -m venv .venv` followed by
`.\.venv\Scripts\Activate.ps1`; the commands below are otherwise the same.
The scripts use a noninteractive Matplotlib backend and do not need a display.

## Reproduce the experiments

The archived manuscript results are in `outputs/`. To regenerate everything in
a separate directory without overwriting them, run these commands in order:

```sh
python waveform_rff_experiment.py --theorem-sweeps --refinement --strict --output reproduced
python monolithic_reference.py --strict --output reproduced
python lambda_limit_experiment.py --strict --output reproduced
python check_results.py --require-refinement --require-lambda-sweep --output reproduced
```

The second command reads the baseline configuration and trajectories produced
by the first. The last command checks the saved validation summaries and
selected required outputs.
The `--strict` commands return a nonzero exit status if their own validation
fails; the final command also checks the particle-number and inexact-score
sweeps and the refinement diagnostics.
For a quick check of the archived results without rerunning the simulations:

```sh
python check_results.py --require-refinement --require-lambda-sweep --output outputs
```

Run a script with `--help` to see its options. Omitting `--output` writes to
`outputs/` and replaces files of the same names. Numerical values can differ
slightly across Python, NumPy, and linear-algebra-library versions; figure
rendering can also differ across Matplotlib versions. The original calculation
environment was not pinned, so the archived files remain the reference for the
figures supplied with the manuscript.

A complete rerun on macOS with Python 3.12.14, NumPy 2.3.5, and Matplotlib
3.11.2 passed all 16 final validation checks. The saved particle trajectories
agreed with the archived trajectories to within `1.8e-15` in absolute value.
Diagnostics formed by dividing very small outer increments are more sensitive
to roundoff; PNG files need not be byte-identical across rendering environments.

## Model and parameters

The particle experiments use the two-dimensional collision matrix

```text
A(z) = (|z|^2 I - z z^T)/(1 + |z|^2).
```

It is bounded and globally Lipschitz, even and symmetric, and satisfies
`A(z)z = 0`. The score space is the vector-valued space generated by 40 scalar
random Fourier features (20 sine/cosine frequency pairs), with the Frobenius
norm of the coefficient matrix. For the feature matrix `Phi[i,m] = phi_m(x_i)`,
the score fit solves, for each coordinate `a`,

```text
(Phi.T @ Phi/N + lambda I) theta_a = -mean_i partial_a phi(x_i).
```

Thus the score minimizer is computed by a linear solve in the selected finite
feature space, to floating-point accuracy. The system step holds the score
coefficient path fixed, interpolates it linearly in time, and advances the new
particle positions by classical RK4. Temporal interpolation and RK4 introduce
discretization errors; this is a time-discretized outer iteration.

| Parameter | Default |
| --- | --- |
| Particle number | 48 |
| Scalar feature count | 40 |
| Frequency scale | 0.85 |
| Regularization parameter | 0.08 |
| Final time | 1.5 |
| Time subintervals | 150 |
| Maximum outer updates | 16 |
| Base random seed | 20260815 |

The initial clouds are nested samples from a two-component Gaussian mixture.
The feature frequencies use seed `base + 1`, the two initial components use
`base + 101` and `base + 202`, and the fixed score-perturbation direction uses
`base + 303`. The particle-number sweep uses `N = 24, 48, 96` with the same
features. The inexact-score sweep uses perturbation amplitudes
`0, .01, .02, .04, .08, .16`.

increments, feature frequencies, and score coefficients. CSV files contain
the numerical diagnostics, while JSON files record settings and validation
summaries. The static regularization experiment uses prescribed sample sites;
these are separate from the randomly sampled particle clouds.

## Interpretation

The numerical results complement the analytic proofs. The fitted factorial
envelope and the particle-number sweep are diagnostics, not estimates of the
theorem's analytic constants. Persistent score perturbations illustrate bias
in this experiment; the inexact theorem itself supplies an upper bound.
RK4 preserves momentum up to roundoff, while its energy drift is a numerical
integration error. It is not the energy-preserving implicit midpoint method.

The static Gaussian-RKHS calculation illustrates a component invisible to
point evaluations: nodal score values may converge while the RKHS norm and
off-grid values diverge as regularization vanishes. These experiments do not
implement the singular Coulomb dynamics or establish a simultaneous dynamic
particle/zero-regularization limit.
